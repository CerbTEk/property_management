# Treestand Manager brand identity

A CerbTek LLC product. The tree-and-home mark combines the Treestand name with hospitality and property management.

| Color | Hex | Usage |
| --- | --- | --- |
| Evergreen | #123C35 | Primary logo, sidebar, primary buttons |
| Sage | #99CCAD | Selected navigation, highlights, guest-screen accents |
| Ivory | #F5F2E9 | Page backgrounds, reversed logo |
| Ink | #172B27 | Main text |
| Clay | #C77750 | Decorative accents, notice borders |

Ivory on evergreen contrast: 10.88:1; ink on ivory: 13.29:1; evergreen on sage: 6.73:1. Clay on ivory is 3.03:1; use it decoratively rather than for normal text. Muted text uses #51665B.

Use the supplied transparent PNG master assets from the Property Management Google Drive folder. Web delivery copies are in public/brand, including the logo, standalone icon, favicon and touch icon. Maintain proportions and clear space. White variants are rendered with a CSS filter on dark surfaces.

Typography: Manrope for headings, DM Sans for interface text. The raster wordmark retains the supplied lettering. Source logo assets are raster artwork, not editable vector masters.
